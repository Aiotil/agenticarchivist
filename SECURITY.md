# Security

AgenticArchivist syncs private family and institutional archives between devices, so security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** button on this repository's Security tab to send a private report.

Include what you found, how to reproduce it, and which versions are affected. You'll get an acknowledgement, and a fix or mitigation plan once the report is confirmed.

## Scope

Of particular interest:

- Invite links: forging, replaying, or extending an invite
- Role enforcement: a viewer's or removed member's changes being accepted
- Anything that modifies or deletes original files
- Leaking Gemini API keys or identity keys
