# Desktop app

Tauri 2 + Svelte 5 window for Mac and Windows. Not started.

The first prototype here is a 50,000-thumbnail grid served by the background process over local HTTP, measured on Mac and a mid-range Windows laptop. It decides between Tauri and native interfaces per platform.

Screens will be ported from the previous web app: library grid, work editor, grouping review, and settings.
